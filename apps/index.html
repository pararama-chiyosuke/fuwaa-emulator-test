🎮 ゲーム別アイコン
Ver.0.28

好きなゲームをスマホのホーム画面から起動できます。アプリとして追加とショートカットの作り方を選べます。

ふわぁ チンチロ

GAME BOY
ゲームを開く →
チンチロのショートカット
  1. 「チンチロを開く」からChromeでゲームを表示
  2. Chrome右上「︙」→「ホーム画面に追加」
  3. 「ショートカットを作成」を選ぶ

Chromeで「アプリをインストール」しか出ない場合は、端末側の表示に従ってください。

ふわぁ テキポ

GAME BOY COLOR
ゲームを開く →
テキポのショートカット
  1. 「テキポを開く」からChromeでゲームを表示
  2. Chrome右上「︙」→「ホーム画面に追加」
  3. 「ショートカットを作成」を選ぶ

Chromeで「アプリをインストール」しか出ない場合は、端末側の表示に従ってください。

ふわぁ テキポ GBA版

GAME BOY ADVANCE
ゲームを開く →
GBA版のショートカット
  1. 「GBA版を開く」からChromeでゲームを表示
  2. Chrome右上「︙」→「ホーム画面に追加」
  3. 「ショートカットを作成」を選ぶ

Chromeで「アプリをインストール」しか出ない場合は、端末側の表示に従ってください。

※ アプリのインストール画面はChromeが対応時に表示します。ブラウザーやインストール状況により、手動操作が必要です。ゲームには通信接続が必要です。
